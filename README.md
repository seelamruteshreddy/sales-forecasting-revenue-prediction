# Sales Forecasting and Revenue Prediction

## Overview
This machine learning project predicts future sales and revenue for retail businesses.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Plotly

## Project Goals
- Predict future sales
- Improve inventory planning
- Forecast revenue
- Analyze trends

## Models Used
- Linear Regression
- Random Forest
- XGBoost
